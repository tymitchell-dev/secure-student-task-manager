# Secure Student Task Manager (SSTM)

# Overview
The Secure Student Task Manager (SSTM) is a secure web application designed to help students manage academic tasks, courses, and deadlines. The system focuses on organization, productivity, and secure data handling through a structured backend architecture.

# Features
User authentication (registration & login)
Secure password encryption (BCrypt)
Task management (in progress)
Course organization (in progress)
Notifications (planned)
Secure data handling

# Technologies
Java (Spring Boot)
Spring Security
MySQL
Maven
HTML/CSS/JavaScript (planned frontend)

# Project Structure
src/main/java/com/sstm/sstm
│── config        # Security configuration
│── controller    # REST API endpoints
│── model         # Entity classes
│── repository    # Database layer
│── service       # Business logic
